# PYQ Register

**Main directory:** https://kslucorner.in/papers/llb

This independent index has 3-year LL.B. question papers across Semesters 1–6. The source also lists both 80- and 100-mark papers, including a January 2026 pair for Constitutional Law I. It is *not* an official KSLU website. Obtain an official copy when possible.

## Work plan

1. Collect available 2023–2026 papers **for the correct 3-year programme and paper code**.
2. Preserve the PDFs as attachments if distribution permissions permit; otherwise keep the links.
3. Extract each question, assigning a subject, unit, issue, marks and date.
4. Merge near-duplicates into a canonical question bank, but preserve every original paper reference.
5. Estimate **historical frequency**, not future probability of examination.
6. Link each question to a verified model answer and a timed practice attempt.
