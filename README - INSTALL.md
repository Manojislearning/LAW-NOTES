# Installation — Windows and Obsidian

1. Extract `KSLU-LLB-Year-1-Obsidian-Starter.zip` to **Documents**, preserving the top-level folder `KSLU-LLB-Year-1-Obsidian-Starter`.
2. Open **Obsidian**. On its vault switcher, click **Open folder as vault** and select that extracted top-level folder. (If Obsidian is already open, use the vault switcher on the lower left.)
3. Open `HOME - Start Here.md`, then `00-Dashboard/Coverage Status.md`.
4. Enable the **Canvas**, **Properties**, **Templates**, and **Bases** core plugins in Settings → Core plugins if disabled.
5. In Settings → Core plugins → Templates, choose `99-Templates` as the template folder.
6. Open `08-Brain-Branches/First-Year Brain Branches.canvas` to see one working native Obsidian conceptual map.
7. Create new exam-answer notes in the relevant subject folder and insert `Template - Exam Topic`.
8. Make a backup before merging into an existing vault. If you already have a vault, merge only the numbered folders rather than overwriting your existing `.obsidian` settings.

## Important caveats

- No premium plugin or account is required for this base workflow.
- The folder contains fifty unit **checklists** and only **three substantive sample answer notes**, not a fully completed KSLU model-answer encyclopedia.
- Unit maps are based on the KSLU 2018 base scheme with the 2024 Criminal Law I revision. Newer subject-specific college/university circulars take precedence.
- Some syllabus provisions were superseded by later legislation. Read `Current-Law Alerts.md` before preparing final exam answers.
