# Language Papers — Confirm applicability

KSLU's underlying 3-year LL.B. scheme lists:

- **Semester 1:** English, for students who write examinations in Kannada.
- **Semester 2:** Kanoonu Kannada / Kannada Kali, for specified non-Kannadiga students.

They are not included in the ten-core-paper count. Ask the college which paper applies before generating unit notes.

**Source:** https://kslucorner.in/assets/syllabus/kslu-llb-syllabus.pdf (Appendix VI-A course table).
