# Answer Writing Method

There are archived KSLU papers in **80-mark and 100-mark formats**. Do not presume a fixed marks allocation. Confirm the instructions on your own paper before practising.

## Substantive essay answer (typically a long question)

**Issue / short introduction → statutory basis → elements/conditions → explanation under numbered headings → leading judgments (material facts, issue, holding, ratio) → example or application → exceptions or criticism → precise conclusion.**

1. Underline the command word (*explain*, *distinguish*, *critically analyse*, *discuss with cases*).
2. Cite the current article/section accurately, and separately note legacy syllabus wording.
3. Use 2–4 meaningful subheadings; avoid a giant paragraph.
4. Include only authorities directly relevant to the issue and cite them accurately.
5. For a problem question use **IRAC**: Issue, Rule, Application, Conclusion; discuss counterarguments.
6. Match depth to marks and time. Allocate time using the paper's instructions, not an arbitrary word count.

## Short note

**Definition → statutory provision → 2–4 core points → one case/illustration → conclusion.** Do not reproduce the whole essay.

## One-minute revision

Capture **meaning + provision + 3 elements + 1 case + 1 exception**.

## Self-review rubric (0–2 each, 10 marks total — private practice only)

- Legal accuracy (0–2)
- Completeness and relevance (0–2)
- Statutory authorities (0–2)
- Judgments and application (0–2)
- Organisation and clarity (0–2)

A private practice rubric is **not** a KSLU marking scheme.
